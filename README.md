# AI Website Workflow

Workflow de IA desenvolvido com **Python, LangGraph e LangChain** para criação e melhoria de websites através de agentes especializados.

## Objetivo

Automatizar o desenvolvimento de sites utilizando um workflow estruturado para:

* Criar novos websites.
* Melhorar websites existentes.
* Analisar e aprimorar UX/UI.
* Gerar e atualizar código.
* Utilizar Tool Calling.
* Manter **estado persistente** durante o workflow.

## Workflow

```text
Requirements / Existing Website
              ↓
           Research
              ↓
            Design
              ↓
           Content
              ↓
             Code
              ↓
        Generated Files
```
